# PlacementFinder — Vishi Talent Hub

Static recruitment and placement website for Vishi Talent Hub: searchable job board, employer and job-seeker panels, candidate dashboard, and WhatsApp apply/enquiry.

## Status — read this first
- This is a static site. It does not store accounts or entered data itself.
- Login page is at `#login`. The "Continue with Google" button is a ready placeholder only — it is not working yet and needs a Google Cloud OAuth Client ID and a backend.
- Registration / applications currently go via WhatsApp.
- Job listings in this version are example roles with indicative salaries only, not live vacancies.

## Run it
Open `index.html` in a browser, or enable GitHub Pages for this repository (Settings → Pages → Deploy from the `main` branch) to host it.
